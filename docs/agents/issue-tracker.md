# Issue tracker: GitHub

Issues and specs live in GitHub Issues for
`undacmic/langchain-pdf-inspector`. Use the `gh` CLI.

## Conventions

- Read an issue’s complete body and comments before working on it.
- Search existing issues before creating tickets to avoid duplicates.
- Publish each approved ticket as a separate GitHub issue.
- Link child tickets using native sub-issue relationships.
- Represent blockers with native issue dependencies. If unavailable,
  include a “Blocked by” section referencing the blocking issues.
- Create blockers before dependent tickets.
- Work tickets whose blockers are all completed.
- Obtain approval of a proposed breakdown before publishing it.

## Pull requests as a triage surface

PRs as a request surface: no.
